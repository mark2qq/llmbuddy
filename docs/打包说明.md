# 本地大模型服务 · 打包说明（v2 · onedir + 内嵌后端）

本文档说明如何把 `E:/llm-service`（PySide6 桌面客户端 + FastAPI 后端 + llama.cpp 引擎）
打包为**一键安装的 Windows 安装程序**。

## 1. 架构与产物形态（v2 变更）

| 项 | v1（旧） | v2（当前） |
| --- | --- | --- |
| 客户端形态 | onefile 单 exe | **onedir**（exe + `_internal/`） |
| 后端依赖 | 需随包携带 `venv` | **内嵌于 exe**（fastapi/uvicorn/httpx/psutil 全打包） |
| 后端启动方式 | `venv\Scripts\python.exe backend\serve.py` | `LLMDesktop.exe --backend`（exe 自身，无外部 Python） |
| 引擎 | `engine/` 全量 2.8GB | `engine-runtime/` CPU 精简版 **41MB**（剔除 CUDA/ROCm/Vulkan） |
| 安装包语言 | 英文 | **简体中文**（ChineseSimplified.isl） |
| 安装目录 | `C:\Program Files\LLMDesktop`（固定） | 可选，默认 `{autopf}\LLMDesktop` |

选 onedir 的理由：C/S 场景后端进程（`--backend`）会被反复重启，onefile 每次都要
解压自身（数十 MB）且临时目录可能被清理，启动慢且不稳；onedir 直接运行安装目录。

安装后目录布局：

```
C:\Program Files\LLMDesktop\
├── LLMDesktop.exe              # 主程序（GUI；加 --backend 参数即内嵌后端服务）
├── _internal\                  # PyInstaller 运行时依赖（PySide6/fastapi/uvicorn/...）
├── engine\                     # llama.cpp CPU 运行时（llama-server.exe + DLL，41MB）
├── backend\                    # 后端源码（可选组件：serve.py + core + routers）
├── models\                     # 模型目录（空占位，客户端「模型库」页下载到此）
└── unins000.exe                # 卸载程序

%LOCALAPPDATA%\LLMDesktop\
├── config.json                 # 客户端配置（安装目录只读，配置外置）
└── cache\                      # 注册表/API Key/目录缓存（registry.json 等）
```

## 2. 环境要求（构建机）

| 组件 | 版本 / 说明 |
| --- | --- |
| Windows | 10 / 11（x64） |
| Python | 3.11（`C:/Program Files/Python311/python.exe`） |
| 依赖包 | PySide6 6.12、fastapi、uvicorn、httpx、psutil、pyinstaller ≥ 6.x |
| Inno Setup 6 | https://jrsoftware.org/isdl.php （含 `ISCC.exe`） |
| 中文语言包 | `ChineseSimplified.isl` 放入 Inno 的 `Languages\` 目录 |

> 安装 Inno Setup 时可无人值守：`innosetup-6.x.x.exe /VERYSILENT /CURRENTUSER`。

## 3. 一键构建

在 `E:/llm-service` 根目录运行：

```bat
client\build\build.bat
```

流程（三步全自动）：

1. **PyInstaller**：`pyinstaller client/build/pyinstaller.spec --noconfirm --clean --distpath dist --workpath build/pyi`
   - 入口 `client/main.py`；`--backend` 分支在运行时 import 内嵌的 `serve`
   - 收集 `resources/styles.qss`、`core/catalog_builtin.json`
   - `hiddenimports` 覆盖 PySide6 子模块 + 后端全家桶 + 业务包
2. **Inno Setup**：`ISCC client/build/inno_setup.iss`
3. 产物：
   - onedir：`dist/LLMDesktop/`
   - **安装包：`client/build/installer/LLMDesktop-Setup-1.0.0.exe`**

也可分步手动执行（见 build.bat 内命令）。

## 4. 关键文件说明

### `client/build/pyinstaller.spec`

- `pathex=[CLIENT_DIR, REPO_DIR]`：REPO_DIR 使 `serve.py` 可被 import（内嵌后端）
- `hiddenimports`：PySide6.* / fastapi / starlette / uvicorn / pydantic / httpx / psutil
  / serve / core.* / routers.* / client 业务包
- `datas`：`resources/styles.qss` → `resources`；`core/catalog_builtin.json` → `core`
- `console=False`（窗口程序）、`upx=False`（避免压缩 DLL 引发运行期问题）
- `excludes`：tkinter/matplotlib/numpy/QtWebEngine 等大而无关的模块

### `client/build/inno_setup.iss`

- `[Components]` 组件化安装：主程序（固定）/ 推理引擎 / 后端源码（可选）
- `[Files]`：`dist\LLMDesktop\*` → `{app}`；`engine-runtime\*` → `{app}\engine`
- `[Dirs]`：`{app}\models`、`{app}\backend\logs`、`{app}\backend\cache` 占位
- `[Run]`：安装后自启一次（可勾选）
- `[UninstallDelete]`：卸载清 logs/cache 与 `{localappdata}\LLMDesktop`；
  **保留 `{app}\models`**（用户下载的模型，避免误删大文件，如需删除请手动清理）

### `engine-runtime/`（CPU 精简引擎）

从 `engine/`（2.8GB，含 CUDA/ROCm/Vulkan）复制的 CPU 运行时子集（41MB / 36 文件）：

- `llama-server.exe`
- `ggml.dll`、`ggml-base.dll`、`ggml-cpu-*.dll`（各代 CPU 指令集变体）
- `libllama.dll`、`libllama-common.dll`、`libllama-server-impl.dll`、`libllama-quantize-impl.dll`
- `libmtmd.dll`、`libc++.dll`、`libomp.dll`、`libwinpthread-1.dll`、`libunwind.dll`
- 各开源 LICENSE 文件

如需重新生成：从 `engine/` 复制上述清单即可（或直接复用仓库内 `engine-runtime/`）。
**已实测**：精简版可正常加载 qwen3-4b 并完成推理。

## 5. 运行时行为（安装后）

- 双击 `LLMDesktop.exe`：GUI 启动；若后端未就绪，弹窗「是否现在启动」→ 确认后
  以 `[exe, --backend]` 子进程方式拉起内嵌 FastAPI 服务（注入 `LLM_*` 环境变量）
- 后端引擎路径：`{app}\engine\llama-server.exe`（经 `LLM_ENGINE` 注入）
- 模型目录：`{app}\models`（在「模型库」页浏览/下载；已有 GGUF 也可在「设置」页
  改指向其它目录）
- 崩溃自愈：GUI 看护后端（`auto_restart`），后端 watchdog 看护各引擎进程
- 关窗 = 最小化到托盘；托盘「退出」才终止后端
- 网关默认 `127.0.0.1:8000`（OpenAI 兼容 `/v1/*` + 管理 `/api/v1/*`）

## 6. 环境变量（客户端 → 后端）

`BackendLauncher` 拉起 `--backend` 子进程时注入（来自 `config.json`）：

| 变量 | 含义 |
| --- | --- |
| `LLM_HOST` / `LLM_PORT` | 网关监听地址（默认 127.0.0.1:8000） |
| `LLM_ENGINE_PORT` | 引擎内部基端口（默认 7999，仅 127.0.0.1） |
| `LLM_MODELS_DIR` | GGUF 模型目录 |
| `LLM_N_CTX` / `LLM_N_THREADS` / `LLM_N_GPU_LAYERS` | 加载参数 |
| `LLM_API_KEY` | 网关鉴权（空=本地开放） |
| `LLM_DEFAULT_MODEL` | 默认模型名 |
| `LLM_ENGINE` / `LLM_ENGINE_EXE` | llama-server.exe 路径（后端读 `LLM_ENGINE`） |
| `LLM_ENGINE_KEY` | 引擎内部鉴权（默认 local） |

## 7. 常见问题

- **PyInstaller 报 `NameError: __file__`**：spec 中已用 `SPECPATH` 兼容（PyInstaller ≥ 6）。
- **安装包编译报缺少语言文件**：确认 `ChineseSimplified.isl` 在 Inno 的 `Languages\` 目录。
- **后端启动失败**：查看客户端「控制台」页运行日志；确认 `{app}\engine\llama-server.exe` 存在。
- **无法加载模型**：确认 `{app}\models` 下有 GGUF 文件，或在「设置」页把模型目录指向已有模型所在目录。
- **中文乱码**：客户端已设 `PYTHONIOENCODING=utf-8` / `PYTHONUNBUFFERED=1`。
- **端口被占用**：客户端启动前会自动探测 8000/7999；被占用时在「设置」页更换端口。
